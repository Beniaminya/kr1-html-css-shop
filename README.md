# Зелёный дом

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

«Зелёный дом» — учебный многостраничный сайт интернет-магазина комнатных растений. На сайте можно посмотреть каталог, открыть страницу товара, изучить характеристики растения и заполнить форму заявки.

## Структура проекта

- `index.html` — главная страница;
- `catalog.html` — каталог растений и статический блок фильтров;
- `product.html` — страница монстеры с описанием и таблицей характеристик;
- `order.html` — форма оформления заявки;
- `contacts.html` — контакты и форма обратной связи;
- `css/style.css` — общий файл стилей;
- `js/main.js` — открытие модального окна и проверка демонстрационных форм;
- `images/` — локальные изображения растений;
- `README.md` — описание проекта;
- `.gitignore` — список файлов, исключённых из Git.

## Используемые технологии

- HTML5 и семантические теги;
- CSS3;
- Flexbox и CSS Grid;
- CSS-переменные;
- базовая методология БЭМ;
- минимальный JavaScript;
- Git, GitHub и GitHub Pages.

## Обязательные страницы

- Главная страница содержит hero-блок, преимущества, популярные товары и отзывы.
- Каталог содержит четыре карточки товаров, категории и статический фильтр.
- Страница товара содержит изображение, описание, цену и таблицу характеристик.
- Страница заявки содержит форму с HTML-валидацией.
- Страница контактов содержит вымышленные контактные данные и форму обратной связи.

## Как открыть проект

1. Скачайте или клонируйте репозиторий.
2. Откройте файл `index.html` в браузере.
3. Для просмотра опубликованной версии перейдите по ссылке GitHub Pages.
